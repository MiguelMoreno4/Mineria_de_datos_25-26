# Mineria_de_datos_25-26
Contiene las prácticas necesarias para la evaluación de la asignatura "Minería de datos y el paradigma Big Data" impartida como asignatura optativa para el grado de ingeniería de software de la universidad Complutense de Madrid y correspondiente al Plan 2019-26. A continuación dejo el enlace a la ficha docente dónde se describen las aptitudes necesarias para pasar la asignatura. https://web.fdi.ucm.es/UCMFiles/pdf/FICHAS_DOCENTES/2025/8919.pdf 
Aquí dejo un breve resumen del temario:
1- Introducción y conceptos básicos: inteligencia del negocio, paradigmas de representación de datos, técnicas de minería de datos y campos
de aplicación.
2- Almacenamiento de datos. Paradigmas complementarios al modelo relacional:
2.1- Paradigma Data warehouses.
2.2- Paradigma Big Data: bases de datos distribuidas y/o NoSQL (MongoDB y Neo4j).
3- Fundamentos de la Minería de Datos:
3.1- Preprocesamiento.
3.2- Modelos de predicción (Árboles de decisión, Clustering, Naive Bayes).
4- Minería de Datos Avanzada:
4.1- Minería de textos.
4.2- Minería de grafos.
